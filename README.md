## 📌 Executive Summary
This project presents an automated diagnostic support system for detecting thoracic conditions from chest X-ray images using the **DenseNet-121** deep learning architecture combined with contrast enhancement algorithms (CLAHE) and an interactive **Gradio** web interface.

## 🚀 Features
- **Deep Learning Model:** DenseNet-121 architecture for feature extraction and classification.
- **Image Preprocessing:** CLAHE (Contrast Limited Adaptive Histogram Equalization), Gaussian smoothing, image normalization, and resizing (224x224).
- **Multi-Class Classification:** Classifies chest X-rays into **Normal**, **Pneumonia**, and **Tuberculosis**.
- **Interactive Web Interface:** Real-time prediction display with confidence probability distributions using Gradio.
